#### What I build

**Retrieval and LLM systems**
Hybrid retrieval (dense embeddings + BM25 with reciprocal rank fusion), confidence
gating so the model declines instead of hallucinating, and streamed answers with
citations. Built on Gemini embeddings and Supabase pgvector.

**Data analysis and dashboards**
Turning messy exports (marketplace CSVs, survey results, spreadsheets nobody wants to
touch) into interactive dashboards. Python, pandas, Streamlit, plotly.

**Model deployment**
Getting models out of the notebook: FastAPI services, containerised inference,
AWS SageMaker, Hugging Face Spaces.
